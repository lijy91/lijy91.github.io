im in ur computer 😼

A tiny script that checks whether the apps on your computer depend on packages I wrote.

Run it

Open a terminal and paste:

curl -fsSL https://lijy91.github.io/im-in-ur-computer.sh | sh

Works on macOS and Linux. Takes a few seconds.

Options

Pass options after sh -s --:

curl -fsSL https://lijy91.github.io/im-in-ur-computer.sh | sh -s -- -v
-vList which apps depend on which packages.
-d dirSearch only this directory. Can be repeated.
-iCase-insensitive match.
-hShow help.

How it works

Apps that use open source packages usually ship a NOTICES file listing the license of every package they depend on. That's where authors get credited, one copyright line at a time.

The script looks through your installed apps (and input methods on macOS), unpacks those files, and searches for my name.

Is it safe?

  • It only reads files. Nothing is installed, changed, or uploaded.
  • No network requests after the download.
  • It's a short shell script. Read it before you run it — you should do that with any curl | sh.
